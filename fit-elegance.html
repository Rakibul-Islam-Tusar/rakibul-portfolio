Production performance decision
Making a 3,000+ row fabric catalog practical at the counter

After the client’s fabric data was migrated from Excel, loading the full catalog into a licensed Kendo MultiColumnComboBox became a bottleneck. I changed the lookup strategy to return an initial top 50 result set, indexed the fabric barcode/name search path in SQL Server, and enabled live server-side filtering. The browser no longer needed the full catalog before a user could begin searching, making fabric selection more responsive and scalable for branch operations.
