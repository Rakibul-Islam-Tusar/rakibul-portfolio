# Rakibul Islam Tusar — Portfolio

A lightweight, responsive portfolio designed for static hosting on Somee. It has no build step and no package dependencies.

## Preview locally

Open `index.html` in a browser. For the most accurate preview, serve the folder with any local static server.

## Publish to Somee

1. Open the Somee file manager for your website.
2. Upload `index.html`, `Web.config`, `robots.txt`, and the entire `assets` folder to the website root.
3. Confirm that `index.html` is in the root, not inside another folder.
4. Open the assigned Somee URL and test the navigation and email button.

## Before sharing publicly

- Confirm the GitHub profile URL in `index.html`.
- Follow `assets/images/README.md` to add the professional portrait and safe project screenshots. The site detects them automatically.
- Add a resume link when the final PDF is available.
- When a custom domain is ready, add a canonical URL and `sitemap.xml` for stronger search indexing.
- If exact employment dates are confirmed, add them to the Experience section.

## Search indexing

The page includes descriptive metadata, semantic headings, crawl permissions, social sharing metadata and Person structured data. After deployment, submit the public URL through Google Search Console to request indexing.
