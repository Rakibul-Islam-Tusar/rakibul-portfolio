# Portfolio image placement

The website is complete without image files and displays custom illustrative UI by default. Add any optional file below and the corresponding visual will be replaced automatically.

## Professional portrait

- Filename: `rakibul-islam-tusar-profile.webp`
- Recommended size: 800 × 1000 px (4:5 portrait)
- Placement: hero section
- Use a clear head-and-shoulders photo with a plain or softly blurred background, natural expression, and neutral clothing.
- Avoid passport-style crops, casual selfies, busy backgrounds, and heavy filters.

## Tailoring Management System

- Filename: `tailoring.webp`
- Recommended size: 1200 × 900 px (4:3)
- Placement: large featured-project visual
- Show an anonymized order workflow, fabric grid, or demo dashboard.

## Fixed Asset & CAPEX Management

- Filename: `fixed-asset.webp`
- Recommended size: 1200 × 750 px (16:10)
- Placement: Fixed Asset project card
- Show an anonymized workflow, approval stages, or a demonstration dashboard.

## Distribution Management System

- Filename: `dms.webp`
- Recommended size: 1200 × 750 px (16:10)
- Placement: DMS project card
- Show an anonymized order summary, distribution flow, or demo analytics.

## Export and privacy rules

- Prefer WebP at 75–82% quality and keep each file below 250 KB.
- Do not add generic stock coding photos; the built-in illustrations are more relevant.
- Never expose client names, customer details, phone numbers, credentials, connection strings, internal URLs, source code, or private reports.
- If a real screenshot cannot be safely anonymized, keep the built-in illustrative visual.
